about=RMA GeoHydro is an open-source QGIS plugin developed by Riller Mairon de Oliveira Alves.
    The plugin supports assisted processing and classification of CAD/DXF linear features, including topographic divides, drainage channels, and downchutes.
    Its initial features include preliminary geometric validation, connectivity diagnostics, vector data export, and optional polygon generation from closed boundaries.
    The plugin is primarily intended for surface drainage applications involving mining embankments, waste rock dumps, and geotechnical structures.
    RMA GeoHydro aims to improve geospatial data organization and support technical engineering workflows.
    Version 0.1.0 is an experimental release intended for testing and continuous improvement.
    The plugin does not perform hydraulic sizing or fully automated drainage network design.
